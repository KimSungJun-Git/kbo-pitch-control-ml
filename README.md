## 📌 1. 프로젝트 요약 (Executive Summary)

야구 투구의 제구 성공 여부(`control_success`)를 투구 직전 시점의 경기 상황, 타자/투수 매치업, 이전 누적 성적(`asof_*`)만을 활용해 확률값(0~1)으로 예측하는 **극저신호(Low-signal) 정형 데이터 최적화 과제**입니다.

단순 모델 튜닝이나 블랙박스 앙상블 대신, **철저한 피처 데이터 감사(Audit)**, **Brier 지표의 볼록성을 활용한 폐형해(Closed-form) 사후보정**, **도메인 채널별 베이지안 수축(Shrinkage) 최적화**를 통해 일관된 성능 개선을 달성했습니다.

```

```

## 🎯 2. 핵심 엔지니어링 돌파구 (Key Technical Breakthroughs)

### ① 데이터 감사(Audit): 잠재된 누적 통계 분해 (+51.91점)
* **문제**: 베이스라인의 핵심 피처 `asof_pitcher_n`이 당해 시즌 누적이 아니라 **커리어 통산 투구수**로 집계되어 당해 시즌의 폼/신호가 희석됨.
* **해결**: 컬럼 전수 감사를 통해 정수 카운트를 역산 복원하고, **커리어 통산 성분과 당해 시즌 성분을 엄격히 분리한 8종 파생 피처 구축**. 단일 수정으로 **+51.91점 도약(t41)**.

### ② 추론-학습 정합성(Skew) 및 누수 제거 (+20.66점)
* **문제**: 학습 시점(Pandas groupby 누적 집계)과 실시간 추론 시점(사전 저장된 스냅샷 매핑) 간의 피처 계산 시점 불일치 발견.
* **해결**: 피처 빌더 파이프라인 단일화 및 스냅샷 링크 검출기 도입으로 **추론 왜곡 해소 (+20.66점, t45)**.

### ③ 리더보드 폐형해(Closed-form) 기반 수학적 사후보정 (+35.25점)
* **문제**: 연도별 제구 성공률 하락(2019 .5647 → 2024 .4861)으로 인해 2025년 평가 데이터의 확률값이 과대 추정됨.
* **해결**: 대회 지표인 Brier 점수가 사후 오프셋($\hat{r}$) 및 스케일($\alpha$)에 대해 **수학적으로 완전한 2차 포물선(Quadratic)**을 그린다는 점을 증명:
  $$p' = \hat{r} + \alpha(p - \hat{r}) + \beta$$
* 탐침(Probe) 제출 2점만으로 2차식의 극점을 대수적으로 역산하여 **$\alpha^* = 1.108, \beta^* = 0.0024$ 폐형해 도출 (학습 0회로 +28.98점 도약, t62/t83)**.

### ④ 채널별 베이지안 수축(Shrinkage $K$) 최적화 (t164 챔피언, +9.10점)
* **문제**: 소표본 선수의 과적합을 막는 기존 전역 수축 상수($K=25.0$)가 투수/타자/팀별 정보량 차이를 반영하지 못함.
* **해결**: 도메인 채널별(투수, 타자, 팀, 카운트) 정보 밀도에 맞춰 shrinkage 파라미터를 개별 딕셔너리로 최적화. **역대 최고점 1137.4560 달성**.

## 🏗️ 3. 최고점 모델 아키텍처 (`t164_shrink_deploy1137`)

* **앙상블 구성 (다양성 극대화 블렌드)**:
  1. `no_asof + tier` LightGBM (가중치 0.485)
