> **최종 제출 패키지**: [`t164_shrink_deploy1137/`](t164_shrink_deploy1137/)  
> **실험 이력**: 120여 회 단일변수 통제 실험 전수 기록 ([`SCORECARD.md`](SCORECARD.md))

## 1. 프로젝트 요약

야구 투구 단위의 제구 성공 여부(`control_success`)를 투구 직전 경기 상황, 볼카운트, 투수/타자 맞대결, 이전 누적 성적(`asof_*`)만으로 예측하는 과제입니다. 

투구 직전 정보만 주어지며 실제 투구 궤적이나 판정 결과는 주어지지 않아, 타깃과의 상관계수가 약 0.104에 불과한 극저신호(low-signal) 정형 데이터입니다.

단순 모델 튜닝이나 맹목적 앙상블은 대부분 손해로 끝났습니다. 유의미한 점수 향상은 다음 네 가지 축에서만 나왔습니다:
1. **피처 데이터 감사**: 컬럼 정의와 집계 방식을 원천 검증해 오염된 통계 분리
2. **학습/추론 스큐 제거**: 배치 학습과 실시간 서빙 파이프라인의 계산 시점 정합
3. **수학적 사후보정**: Brier 손실 함수의 2차식 성질을 이용한 닫힌해(Closed-form) 극점 도출
4. **채널별 베이지안 수축**: 소표본 선수의 표본 크기에 따른 사전확률 수축 상수 최적화

```text
Baseline (941.72)
  └─ [t41, t45] 피처 데이터 감사 및 추론 스큐 제거 (+83.53) ──► 1025.25
        └─ [t62, t83] Brier 곡률 기반 닫힌해 사후보정 (+65.62) ──► 1090.87
              └─ [t157] 이종 멀티태스크 신경망 블렌드 (+37.48) ──► 1128.35
                    └─ [t164] 채널별 베이지안 수축 최적화 (+9.10) ──► 1137.4560 (최종 챔피언)
```

## 2. 주요 개선 과정

### 2.1 커리어 누적치와 시즌 성분 분리 (+51.91점, t41)
* **문제**: 베이스라인의 핵심 피처인 `asof_pitcher_n`이 당해 시즌 누적이 아니라 선수 통산 투구수로 집계되어 있었습니다. 이로 인해 베테랑 투수의 당해 연도 폼 변화가 과거 데이터에 묻혀 희석되었습니다.
* **해결**: 컬럼 정의를 감사하여 `round(rate * n)`으로 통산 성공 횟수를 역산한 뒤, 당해 시즌 직전 스냅샷을 차감해 순수 당해 시즌 성분 8종을 신규 분리했습니다.

### 2.2 학습-추론 간 계산 스큐 해소 (+20.66점, t45)
* **문제**: 학습 데이터는 Pandas groupby 누적 집계로 만들고, 추론 환경(`script.py`)에서는 피클 스냅샷(`snap.pkl`)을 조회하도록 설계되어 일부 피처의 집계 분모와 시점이 어긋나 있었습니다.
* **해결**: 피처 빌더 코드를 단일화하고 스냅샷 링크 검출기를 도입해 추론 시점의 왜곡을 없앴습니다.

### 2.3 리더보드 닫힌해를 통한 확률 사후보정 (+35.25점, t62/t83)
* **문제**: 연도별 제구 성공률이 매년 하락(2019년 0.5647 → 2024년 0.4861)함에 따라, 2025년 평가 데이터에 모델 출력이 전반적으로 과대 추정되었습니다.
* **해결**: 대회 지표인 Brier 점수가 오프셋($\hat{r}$)과 스케일($\alpha$)에 대해 엄밀한 2차 포물선을 그린다는 점을 증명했습니다.
  $$p' = \hat{r} + \alpha(p - \hat{r}) + \beta$$
* 탐침 제출 2점만으로 2차 방정식의 극점을 대수적으로 역산해 최적 계수($\alpha^* = 1.108, \beta^* = 0.0024$)를 도출하고 추가 학습 없이 반영했습니다.

### 2.4 채널별 베이지안 수축 상수 최적화 (+9.10점, t164 챔피언)
* **문제**: 표본이 적은 선수의 과적합을 막는 기존 수축 상수($K=25.0$)가 단일값으로 고정되어 투수, 타자, 팀별 정보 밀도 차이를 반영하지 못했습니다.
* **해결**: 투수($K=25$), 타자($K=15$), 팀($K=50$) 등 도메인 채널별로 최적 $K$ 값을 분리 적용하여 최종 최고점(1137.4560)을 달성했습니다.

## 3. 최고점 모델 구조 (`t164_shrink_deploy1137`)

* **앙상블 구성**:
  - `no_asof + tier` LightGBM (가중치 0.485)
  - `tm_full + tier` LightGBM (가중치 0.485)
  - `구종 보조과제 멀티태스크 NN` (가중치 0.03, 5시드 순수 NumPy 추론)
* **추론 및 규정 준수**:
  - **행 독립성 (규칙 4)**: 단일행 추론과 전량 추론 간 예측 오차 $0.000\text{e+}00$ 확인.
  - **추론 시간**: 24.5만 행 기준 제한 시간 600초 중 23초 만에 추론 완료.
