## 2. 타깃 변수(`control_success`) 정의 및 특성

대회 규정상 결과값은 제구 성공(1)과 제구 실패(0)의 이진 라벨이며, 제출값은 0과 1 사이의 확률값입니다.

### 2.1 판정 구조
보조 라벨 분석 결과, 제구 성공 여부는 다음 기준에 따라 산출되었습니다:

1. **가운데/위험 코스(`middle_rate = 1`)**: 포수 요구 위치와 무관하게 존 한가운데로 몰린 공 → 제구 실패(0)
2. **포수 요구 반대 투구(`reverse_rate = 1`)**: 포수 미트 위치와 반대 방향으로 형성된 실투 → 제구 실패(0)
3. **일반 투구(Clean, 약 65.5%)**: 위 두 실투를 제외한 투구로, 대부분 제구 성공(1)으로 판정 (볼 판정 시에만 약 0.591로 하락)

### 2.2 기저율 추세와 시계열 드리프트
* **평균 성공률**: 6개년 전체 제구 성공률은 약 0.5238입니다. 투구 직전 정보만으로 결과와의 상관계수는 약 0.104 수준입니다.
* **연도별 기저율 하락**:
  - 2019년: 0.5647
  - 2020년: 0.5312
  - 2021년: 0.5189
  - 2022년: 0.5094
  - 2023년: 0.4982
  - 2024년: 0.4861
  - 2025년 (평가 데이터 실측 역산): 0.4609
* 과거 데이터로 학습한 모델은 당시의 높은 기저율을 기준으로 예측하므로, 2025년 평가 시 전반적으로 확률을 과대 추정하게 됩니다. 이에 따라 사후 기저율 오프셋 및 캘리브레이션($\alpha^*, \beta^*$) 보정이 필요합니다.

## 4. 데이터 감사 및 전처리 핵심 사항

### 4.1 커리어 누적치와 시즌 내 성분 분리
`asof_pitcher_n`은 시즌이 바뀌어도 초기화되지 않는 통산 투구수였습니다. `round(rate * n)`으로 성공 횟수를 계산한 뒤, 당해 시즌 직전 스냅샷 누적치를 차감해 당해 시즌 내 성분 8종을 분리했습니다.

### 4.2 학습/추론 파이프라인 정합성
학습 시에는 groupby 누적으로 계산하고 추론 시에는 사전 생성된 pickle 스냅샷을 참조하면서 일부 피처의 집계 시점과 분모가 어긋나 있었습니다. 피처 생성 파이프라인을 단일 코드로 통일해 스큐를 해소했습니다.

### 4.3 결측치 처리 (-999 센티넬 대치)
이력이 부족한 표본의 결측치에 median을 대치하면 리그 평균 수준으로 왜곡됩니다. 결측값을 `-999` 상수로 지정하여 트리가 결측 자체를 독립적인 분기 조건으로 학습하도록 처리했습니다.

### 4.4 채널별 베이지안 수축 (Shrinkage)
소표본 선수의 극단적인 성공률(예: 5구 5성공 = 1.0)에 따른 과적합을 방지하기 위해 다음 수축 공식을 적용했습니다:
$$\hat{p} = \frac{n \cdot \bar{y} + K \cdot \mu}{n + K}$$
단일 상수를 사용하는 대신, 투수($K=25$), 타자($K=15$), 팀($K=50$) 등 도메인 그룹별로 최적 $K$ 값을 분리 적용했습니다.

### 4.5 행 독립 추론 준수 (규칙 4)
평가 데이터(`test.csv`) 내 다른 행을 집계하거나 참조하는 행위는 엄격히 금지됩니다. 모든 피처 생성 함수는 단일 행 입력 시에도 동일하게 동작하도록 설계되었습니다.

## 5. 보조 데이터: `trackman_history.csv`

2019~2024년 정규리그 및 퓨처스리그 투구의 3D 레이더 추적 로그입니다 (1,793,078행).

| 컬럼명 | 단위 | 설명 |
|---|---|---|
| `rel_speed` | mph | 릴리스 시점 초속 (구속) |
| `spin_rate` | rpm | 분당 회전수 |
| `induced_vert_break` | inch | 유도 수직 무브먼트 |
| `horz_break` | inch | 수평 무브먼트 |
| `extension` | ft | 투구판 기준 릴리스 확장 거리 |
| `rel_height` / `rel_side` | ft | 릴리스 3차원 좌표 |
| `zone_speed` | mph | 홈플레이트 통과 종속 |
| `tagged_pitch_type` | 문자열 | 태깅 구종 |
| `pitch_type_group` | 범주형 | 대분류 구종 (`fastball`, `breaking`, `offspeed`) |

* **활용 방식**: 트랙맨 식별자와 메인 투수 ID 간 1:1 매핑이 없어 단순 결합 시 신호가 희석되었습니다. 이에 따라 트랙맨 피처를 활용하는 전용 모델(`tm_full`)과 기본 모델(`no_asof`)을 각각 독립 학습한 뒤 앙상블 블렌드로 결합했습니다.
